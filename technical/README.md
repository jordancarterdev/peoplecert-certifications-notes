# Technical Artifacts

Included technical formats:

- Python for service-health and backlog metrics
- JSON for service inventory
- YAML for service/agile modeling
- PowerShell for change-validation simulation
- Mermaid for architecture diagrams

Run the Python examples from the repository root:

```bash
python technical/service_health.py
python technical/backlog_metrics.py
python technical/architecture_inventory.py
```
