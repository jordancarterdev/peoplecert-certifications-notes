# Fusion Architecture

## Technology Layer
Microsoft provides the implementation layer: Azure, Windows Server, business applications,
collaboration and communications technologies.

## Service Management Layer
ITIL adds operational discipline: incident management, change enablement, service
configuration and continual improvement.

## Agile Layer
Scrum and scaled-agile methods add product goals, backlog management, incremental delivery,
stakeholder feedback and cross-team coordination.

The three layers are complementary rather than interchangeable.
